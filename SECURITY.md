# Security policy

NEXUS is a local, offline app. Its security model, what it collects and the results of dependency audits are in
[docs/SECURITY.md](docs/SECURITY.md).

## Reporting a vulnerability
Please **do not open a public issue** for security problems. Use GitHub's *Security → Report a vulnerability*
(private advisory) on this repository. Include the NEXUS version, Windows version and steps to reproduce.
You will get an answer as soon as a maintainer can look at it.

## Supported versions
Only the latest release receives fixes.
