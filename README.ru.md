# NEXUS

**Приватный, полностью локальный учёт времени работы с приложениями для Windows 10/11.**
Показывает, сколько времени вы проводите в каждой программе: сколько она была в фокусе и сколько просто
работала. Без аккаунтов, облака, телеметрии и интернета.

[English version](README.md)

## Возможности
- **Два отдельных счётчика на приложение:** время в фокусе (вы реально им пользуетесь) и время работы.
- **Простой и блокировка экрана:** время без мыши и клавиатуры и заблокированный экран не засчитываются
  (простой можно засчитывать в настройках — например, для просмотра видео).
- **День / Неделя / Месяц / Год / Всё время**, выбор даты, история по дням и месяцам, график активности и
  распределение времени между приложениями.
- **Живёт в трее:** при сворачивании окно закрывается и освобождает память, учёт продолжается.
  Автозапуск с Windows (свёрнутым в трей) — по желанию.
- **Переживает выключение, сон и перезагрузку:** данные сохраняются каждые 30 с, при выходе и при завершении сеанса Windows.
- **8 языков интерфейса:** English, Русский, Español, Deutsch, Français, Português (Brasil), 简体中文, 日本語.
- Почти не нагружает систему: ~0 % процессора; в трее остаётся лишь небольшой процесс NEXUS.

## Приватность
- Работает **полностью офлайн**. В NEXUS нет сетевого кода, аналитики, отчётов об ошибках и автообновления.
- Собирает только **название программы** (например, `chrome.exe`) и **время** в фокусе / работы. Не записывает нажатия
  клавиш, заголовки и содержимое окон, буфер обмена, скриншоты и файлы.
- Всё лежит в одном локальном файле SQLite: `%APPDATA%\app.nexus.tracker\nexus.sqlite3`.
- Права администратора не нужны. Приложение не запускает других процессов.
- Подробности и результаты проверок: [docs/SECURITY.md](docs/SECURITY.md).

## Установка
Скачайте со страницы [Releases](../../releases):

| Файл | Для кого |
|---|---|
| `NEXUS_x.y.z_x64-setup.exe` | **Рекомендуется.** Установка для текущего пользователя (без прав администратора), спрашивает язык, добавляет ярлык в «Пуск» и запись об удалении. |
| `NEXUS-x.y.z-portable-x64.zip` | Распакуйте куда угодно и запустите `NEXUS.exe`. Перед удалением папки выключите «Запускать вместе с Windows» в настройках. |
| `SHA256SUMS.txt` | Контрольные суммы файлов. |

Требования: Windows 10 или 11 (x64) и *Microsoft Edge WebView2 Runtime* (есть в Windows 11 и в обновлённой
Windows 10; установщик докачает его, если его нет).

> **SmartScreen:** файлы пока без цифровой подписи, поэтому Windows может показать «Система Windows защитила ваш
> компьютер». Нажмите «Подробнее → Выполнить в любом случае» и сверьте файл с `SHA256SUMS.txt`
> (`Get-FileHash .\NEXUS_*_x64-setup.exe`). Релизы собирает GitHub Actions из исходников этого репозитория.

## Использование
- *Свернуть* отправляет NEXUS в трей: значок открывает окно (левый клик) или завершает приложение
  (правый клик → «Выйти»). В настройках можно сделать так же и для кнопки закрытия (×).
- Порог простоя (1–60 мин), засчитывание простоя, автозапуск и язык — в «Настройках».
- «Настройки → Удалить всю статистику» стирает все данные.

## Сборка из исходников (Windows)
Нужны: [Node.js](https://nodejs.org) 20+, [Rust](https://rustup.rs) stable (MSVC) с «Средствами сборки C++»,
WebView2 Runtime.

```powershell
git clone https://github.com/MAPAKUYA/nexus.git
cd nexus
npm ci
npm run tauri build        # установщик: target\release\bundle\nsis\NEXUS_<версия>_x64-setup.exe
                           # обычный exe: target\release\nexus.exe
```

Разработка: `npm run tauri dev`. Тесты и проверки: `npm test`, `npm run typecheck`, `cargo test -p nexus-core`,
`cargo audit`, `npm audit`, а на запущенном приложении —
`powershell -ExecutionPolicy Bypass -File .\scripts\verify-windows.ps1 -Seconds 60` (процессор, память, сеть).
