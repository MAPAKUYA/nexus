# NEXUS — производительность (версия 1.0.0)

## Что именно делает приложение, пока работает в фоне
Раз в секунду: определить окно в фокусе (`GetForegroundWindow`), время последнего ввода (`GetLastInputInfo`),
признак блокировки (`OpenInputDesktop`) и сложить миллисекунды в память. Раз в 5 секунд: перечислить окна
(`EnumWindows`, ~30 окон) и определить их процессы. Раз в 30 секунд и при выходе: одна транзакция в SQLite.
Больше ничего: нет циклов ожидания «впритык», нет записи на диск каждую секунду.

## Замеры ядра (Linux, релизная сборка, 1 ядро; `cargo run --release --example bench -p nexus-core`)
| Операция | Результат |
|---|---|
| Один замер учёта, 25 запущенных приложений | 1,9 мкс (при 1 замере/с — около 0,0002 % одного ядра) |
| Запись пачки из 25 строк в файл на диске | 0,02 мс (раз в 30 с) |
| База за 5 лет (30 приложений в день, 54 780 строк) | 2,6 МБ |
| Отчёт «день» / «неделя» / «месяц» | 0,07 / 0,10 / 0,31 мс |
| Отчёт «год» | 4,3 мс |
| Отчёт «всё время» (5 лет) | 32 мс |

Отчёт строится только пока окно открыто. Для прошедшего периода обновляется лишь индикатор состояния;
для недели/месяца/года/всего времени — раз в 10 секунд, для текущего дня — раз в 2 секунды.

## Память и процессор: замер на реальном компьютере
Скрипт `scripts/verify-windows.ps1 -Seconds 60`, Windows, 6 логических ядер. «Private bytes» — выделенная
(зафиксированная) память процесса; диспетчер задач по умолчанию показывает другую величину — физический рабочий набор,
который Windows сильно «сжимает» у свёрнутых программ (поэтому там были единицы мегабайт).

| Состояние | Процессов | Память (private bytes) | ЦП за 60 с | Сеть |
|---|---|---|---|---|
| Окно открыто | 7 (NEXUS + 6× WebView2) | 275,5 МБ (NEXUS 59,8 + движок окна ~216) | 0,15 % | только петля `::1`, к другим компьютерам нет |
| Свёрнуто в трей | 1 | 59,7 МБ | 0 % | сокетов нет |

Окно при сворачивании закрывается целиком (процессы WebView2 завершаются), при открытии создаётся заново (~1 с).
Автозапуск стартует без окна. 60 МБ у самого NEXUS.exe — выделенная, а не занятая физически память.

## Как проверить у себя
1. Запустите NEXUS, откройте окно и выполните
   `powershell -ExecutionPolicy Bypass -File scripts\verify-windows.ps1 -Seconds 60`.
2. Сверните окно в трей, подождите 10 секунд и повторите.
3. Скрипт выводит процессы, память, загрузку ЦП и все сетевые сокеты, замеченные за время измерения, отдельно
   «локальные» и «к другим компьютерам», и итоговый вердикт.
